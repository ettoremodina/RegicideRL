Queen tier · Methods

From legal moves to possible worlds.

Four agents form the measured comparison. They share the same rules and action mask but spend radically different amounts of computation on each decision.

Measured in the 400-game dataset

Baseline · no lookahead

Random

Selects uniformly from the legal mask. It tests the environment contract and establishes a floor, not a strategy.

Rule-based · no rollout search

Heuristic

Scores exact defense, exact kills, useful suit powers, conservation of face cards, and the timing of Jesters. Randomized tie-breaking prevents a fixed ordering bias.

Search · 3,000 rollouts per decision

PIMC

Samples hidden deck orders, evaluates each legal root move through heuristic rollouts, and averages their returns. It is simple and effective, but separate worlds can imply incompatible future strategies.

Information-set search · 3,000 iterations per decision

ISMCTS

Builds one tree shared across sampled worlds. Nodes represent information sets; selection considers only currently legal children and uses each action's availability count in UCB1.

Why ISMCTS is the project focus

PIMC: separate answers

A root action is tested in many fully specified deck orders. The rollout can then behave differently because it “knows” each sampled order. Averaging those futures creates strategy fusion: a plan may depend on information the real player will never receive.

ISMCTS: one information tree

Each iteration still samples one possible deck, but all iterations update the same action tree. Availability-aware UCB balances moves that are legal in different sampled states. The chosen move is the most visited legal root child.

sample hidden cards → select legal child → expand one action
                   → heuristic rollout → backpropagate reward
                                      ↖ repeat in the shared tree

Explored, but not measured here

Reinforcement learning · MaskablePPO

PPO

The project includes a Gymnasium wrapper, numeric observations, action masking, training scripts, and a PPO agent adapter. In practice, training took too long for this project and the available results were poor. The report run later failed while loading a missing promoted checkpoint, so PPO is excluded from all measured charts rather than represented by an invalid or incomparable value.

No PPO or AlphaZero datapoints are inferred. The results page contains only completed game rows for Random, Heuristic, PIMC, and ISMCTS.
