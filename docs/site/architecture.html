Jack tier · System design

One engine, several ways to play.

The domain model owns every rule. A Gymnasium adapter turns that mutable game into masked decisions; interfaces and agents consume the same contract, while logging captures the run around it.

The state: information first

Observable to the acting agent

  • Its sorted hand and current player.
  • Current enemy rank, suit, health, accumulated damage, and effective attack.
  • Counts for Tavern, discard, and enemies remaining.
  • Defense phase and required defense.
  • Yield and solo-Jester availability.
  • A 543-bit legal-action mask.

Hidden during real decisions

  • The order of unseen Tavern cards.
  • The order inside future castle tiers.
  • Other hands in multiplayer from the current observer's perspective.

Search agents clone the full internal state, then determinize hidden cards into a possible world consistent with what is known. This prevents direct access to the live deck order.

The action space: 543 stable IDs

A fixed global space allows Gymnasium policies, search trees, recordings, and replays to refer to the same move by ID. A mask removes actions that are illegal in the current hand and phase.

IDs 0–285286 attack actionsYield, singles, Ace pairs, Ace companions, and same-value combinations.
IDs 286–541256 defense subsetsOne bit per slot in the maximum eight-card hand; only minimal sufficient discards remain legal.
ID 542Solo JesterAvailable only at its legal timings.

Why both global and hand-relative encoding? Attack IDs describe card identities and remain stable after a hand is sorted. Defense IDs describe subsets of the current eight hand slots. ActionHandler performs both conversions and produces the legality mask.

Transition contract

Each environment step returns the next mixed observation, a shaped reward, termination flags, and a detailed result. Intermediate enemy defeats receive a small positive signal; victory and defeat receive terminal rewards. Search uses a denser progress evaluation based on enemies defeated, while the experiment records outcomes separately.

The environment currently declares the action mask as its formal Gymnasium observation space. Custom agents also receive raw card and state objects; numeric wrappers turn these into fixed arrays for PPO-style policies.

Reproducibility around the engine

Every experiment freezes its effective configuration, base seed, source revision, metrics, and game-level CSV inside a run directory. Paired comparisons reuse the same seed sequence across agents, so each method sees the same initial shuffle for a given pair.
