A card game built as a search problem.

Regicide AI is a complete Python implementation of the cooperative card game: an official-rules engine, desktop interface, browser control panel, reproducible experiment system, and agents that plan under hidden information.

The central question

How should an agent act when the deck is hidden?

A strong Regicide move depends on cards that have not been revealed. The project therefore compares immediate policies with two kinds of sampled search: PIMC evaluates separate possible worlds, while ISMCTS shares one tree across information sets. The rules engine remains the single source of truth for the UI, training environment, and every search rollout.

What is finished

  • One-to-four-player rules engine, including solo Jesters.
  • Pygame desktop interface and local browser control panel.
  • Gymnasium adapter with masked global actions.
  • Random, rule-based, PIMC, and ISMCTS agents.
  • Run manifests, game datasets, metrics, plots, and API docs.

What this guide covers

This is a navigable project report, not an API reference. It explains the game, the software boundaries, the state and action representations, the evaluated methods, the evidence collected, and the remaining research directions.

For implementation-level detail, open the generated API documentation.
